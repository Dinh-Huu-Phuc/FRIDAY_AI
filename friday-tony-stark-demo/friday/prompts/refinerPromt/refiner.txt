# FRIDAY STT Refiner Specification

Build a production-ready English Speech-to-Text refinement module for FRIDAY.

## Behavior
- Accept a raw transcript, language, conversation hint, and custom vocabulary.
- Correct spelling, punctuation, casing, and contextually misheard words.
- Preserve intent and never answer the transcript.
- Return exactly one corrected sentence with no markdown or explanation.
- Support short smart-home commands and ordinary conversation.
- Prefer deterministic normalization first and use an LLM only for ambiguity.
- Fall back to normalized input when the provider fails or times out.

## Architecture
- Keep provider clients behind a small interface.
- Support Groq and OpenAI-compatible providers through environment variables.
- Never log API keys or raw sensitive content.
- Include typed result objects with provider, fallback, and error metadata.
- Allow custom vocabulary and alias mappings.
- Include focused tests for correction, fallback, timeout, empty input, and secret handling.

## Output
Provide the affected file tree and complete runnable Python for every file. Do not use placeholders, TODOs, or abbreviated code. Respond in English.
