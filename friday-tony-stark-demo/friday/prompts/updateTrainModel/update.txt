# FRIDAY Safe Learning Architecture Upgrade

Act as a senior AI and Python architect. Upgrade FRIDAY's long-term learning pipeline without breaking existing runtime behavior.

## Pipeline
1. Capture eligible user and assistant turns.
2. Normalize and refine noisy text.
3. Attach session, user, provider, language, and timestamp metadata.
4. Redact secrets and personally identifiable information.
5. Apply safety, quality, spam, and duplication filters.
6. Score accepted samples.
7. Store them in a versioned intermediate dataset.
8. Curate a training dataset only after policy thresholds pass.
9. Run training through an explicit batch job.
10. Evaluate the candidate against the active model.
11. Promote only when metrics pass; otherwise reject it.
12. Preserve a complete rollback path and report.

## Non-Negotiable Rules
- Never train after every conversation.
- Never use runtime memory as direct training input.
- Never train on secrets, system errors, spam, unsafe content, or low-quality output.
- Keep model versions, manifests, metrics, and promotion decisions auditable.
- Keep all file operations resilient and deterministic.

## Deliverable
Provide a production-ready architecture and complete Python implementation that fits the existing repository. Include schemas, stores, filters, dataset curation, scheduler, trainer interface, evaluator, registry, reports, tests, and integration points. Use no placeholders or TODOs. Respond entirely in English.
